系统总览

新媒体艺术时间模拟器 · 核心机制说明

一句话概括这个作品

这是一个把当代新媒体艺术生态转译成可玩的时间推进系统的实验作品：你接管一份艺术家档案，在一个创作周期里，通过选择实践谱系、装配方法节点、在不同场域移动做工作、立项攒资源，最后生成一份阶段性创作归档。

它的本质不是"让你玩艺术家"，而是用系统把"创作生态"这个模糊的东西，拆解成可追踪的档案、方法、场域、时间、预算、关系六个维度。

艺术家档案 / 实践谱系

一开始你会测评创作倾向，然后接管一份艺术家档案。档案不是角色，是一份带着履历的实践起点，它决定了你：

  • 初始资源分配（时间/预算/体力/名声）
  • 自带的固定方法节点
  • 额外解锁的节点位置
  • 不同的归档结局偏向

当前预置三个基础实践谱系：

纯研究取向

知识优先 · 低资源高潜力

适合慢慢攒方法论、沉下心做研究，走长线学术/理论路线。

项目生产取向

产出优先 · 资源周转快

适合不断接项目、立项、刷产出，走项目密集生存路线。

场域游牧取向

探索优先 ·多场域解锁

适合到处跑、碰机会、捡随机方法，走奇遇驱动路线。

后续可以扩展更多谱系：建筑跨界、机构策展、开源技术、驻留流浪...

旧版原来有 9 大派系，都可以转成这里的实践谱系。

方法网络 / 实践节点

方法不是传统游戏的"攻击+N"，这个设计思路来自 Agent Skills / 方法论模块化：每个方法就是一块实践节点，插进去就获得一种处理问题和行动的思考方式。

分成五层，对应创作的不同层面：

知识层
认知节点：你怎么看问题、怎么定义问题 → 空间感知协议、批判性转译...
技术层
执行节点：你用什么技术做作品 → 节点锻造、实时渲染、材料试验...
接口层
合作节点：你怎么跟外界对接 → 策展黑话编译器、跨学科翻译...
生存层
后勤节点：你怎么维持创作 → 预算招魂、grant 打猎、兼职缓冲...
偏门手段
非常规操作：特殊场景用法 → 档案打捞术、风险幽默、机构漂移...

不同谱系开局带不同节点，创作过程中可以在场域里捡到新方法，你自由组合出自己的工作网络。

设计思想

这个节点系统本质是在说：一个艺术家的"能力"，其实就是一套可装配的方法论。你拣到什么就用什么，拼出你的工作网络。

场域线路与工作现场

场域不是背景，场域就是生态关系表。不同区域有不同的：

  • 方法节点掉落倾向
  • 关系人物遭遇概率
  • 项目机会类型
  • 资源消耗特征
  • 解锁阶段要求

当前开放六大城市场域：

榕树湾工作区

气质：入门共享 · 夜间社交 · 旧工程整理

深港加速走廊

气质：提案密集 · 品牌对接 · 现场测试

南岭学院与展厅群

气质：讲座评图 · 学院系统 · 作品陈述

离线渲染农场

气质：算力缓存 · 工具重构 · 闭关预演

北方双年展工地

气质：大空间部署 · 团队协作 · 媒体关系

海外驻留港

气质：跨学科相遇 · 原型生产 · 赞助连接

每个大场域下面还有具体工作现场，比如深港走廊里有"提案会议室""黑盒测试场"...进不同现场，消耗不同资源，掉不同东西。

在制项目与排期

这就是你说的"类似挂渲染/种菜"机制：

  • 你可以在当前场域选一个项目"立项"
  • 项目需要若干工作单位周期才能完成
  • 完成后给你对应的资源奖励，可能解锁新方法
  • 同一时间只能挂一个，你可以随时换，但进度不保留

已有项目类型：

  • 创作类：环幕失真仪式...
  • 申请类：驻留申请计划...
  • 整理类：方法模块化整理...
  • 商业类：品牌空间提案...
  • 理论类：方法论宣言重写...

为什么要"挂着"

因为真实创作就是这样：作品不是点一下就出来，它需要时间在后台"生长"。你挂上去，继续跑场域做工作，到点收成。这就是对"创作周期"的模拟。

预算、档案与关系

所有工作都消耗资源，所有收获都增加资源。核心六种资产：

时间

最硬的通货。每做一次工作就消耗时间，到 20 个工作单位就进入本轮归档。

预算

维持创作的燃料。有些场域和项目需要花钱，没钱寸步难行。

体力

高强度工作耗体力，体力太低会影响收益。需要找地方调整恢复。

名声

影响力资产。名声够了才能进高级场域，接大项目。

档案

你做过的东西积累下来就是档案。档案能解锁新可能性。

关系

在场域里认识关系人物攒下的连接。关系能带来特殊机会。

关系人物与场域接口

关系人物不是剧情工具人，他们是制度位置的具象化：

  • 老炮张 → 出来早的地方实践者
  • 王教授 → 学院系统守门人
  • 甲方姐 → 品牌/赞助接口人
  • 孟工 → 技术协作提供者
  • 开源幽灵 → 匿名知识社区
  • 驻留管理员 → 国际场域守门人

在不同场域遭遇不同关系人物，他们会给你不同的选项，影响你的资源和方法积累。

一次完整创作周期

测评创作倾向 → 推荐实践谱系 → 接管艺术家档案 → 配置方法网络 → 进入创作
选场域/工作现场 → 执行现场工作 → 可能遇关系人物 → 可能捡到新方法 → 立项排入在制
工作单位 +1 → 项目推进 → 重复 → 20 单位 → 生成本轮归档

一轮大概 5-15 分钟，骨架已经闭环，可以完整走完全程。

归档机制与后续生成

  • 进度存在浏览器本地，刷新不丢
  • 支持导出/导入归档 JSON，可以备份带走
  • 所有内容都在 data 层，加新谱系/新场域/新方法只需要改数据
  • 预留了后续接 AI 扩写对话和事件的口子，但第一阶段先把骨架做硬
