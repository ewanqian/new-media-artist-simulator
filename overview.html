系统总览

新媒体时间模拟器 · 核心机制说明

一句话概括这个项目

这是一个把当代新媒体艺术生态转译成可玩策略游戏的实验：你扮演一个进入场域的创作者，通过选择流派、装配方法论技能、在不同地图移动做行动、挂项目攒资源，在20回合内走出你自己的创作生涯。

它的本质不是"让你玩艺术家"，而是用游戏规则把"创作生态"这个模糊的东西，拆解成可追踪的时间、资源、场域、技能、关系五个维度。

干员壳体 / 流派

一开始你会测评出倾向，然后选一个"干员壳体"。壳体不是职业，是生存策略的初始包，它决定了你：

  • 初始资源分配（时间/资金/体力/名声）
  • 自带的固定技能
  • 额外解锁的槽位
  • 不同的结局判定偏向

当前预置三个基础流派：

纯 研 究 型

知识优先 · 低资源高潜力

适合慢慢攒方法论、沉下心做研究，走长线学术/理论路线。

项 目 型

生产优先 · 资源周转快

适合不断接项目、挂研发、刷产出，走项目密集生存路线。

场 域 游 牧 型

探索优先 · 多地图解锁

适合到处跑、碰机会、捡随机掉落，走奇遇驱动路线。

后续可以扩展更多流派：建筑跨界型、机构策展型、开源技术型、驻留流浪型...

技能插槽 / 功能芯片

技能不是传统RPG的"攻击+N"，这个设计思路来自 Agent Skills / 方法论模块化：每个技能就是一块功能芯片，插进去就获得一种处理信息和行动的方式。

分成五类槽位，对应不同层面的创作功能：

方法论槽
认知芯片：你怎么看问题、怎么定义问题 → 空间感知协议、批判性转译...
工具槽
执行芯片：你用什么技术做东西 → 节点锻造、实时渲染、材料试验...
接口槽
合作芯片：你怎么跟外界对接 → 策展黑话编译器、跨学科翻译...
生存槽
后勤芯片：你怎么维持创作 → 预算招魂、 grants 打猎、兼职缓冲...
特勤槽
特殊芯片：非常规操作 → 档案打捞术、风险幽默、机构漂移...

不同流派开局带不同槽位，游戏过程中可以在地图里捡到新技能，你自由组合出自己的工作流。

设计思想

这个插槽系统本质是在说：一个艺术家的"能力"，其实就是一套可装配的方法论。你拣到什么就用什么，拼出你的工作流。

地图与场域系统

地图不是背景，地图就是场域生态表。不同区域有不同的：

  • 技能掉落倾向
  • NPC 遭遇概率
  • 项目机会类型
  • 资源消耗倍率
  • 解锁阶段要求

当前开放六大区域：

榕树湾工作区

气质：入门共享 · 夜间社交 · 旧工程整理

深港加速走廊

气质：提案密集 · 品牌对接 · 现场测试

南岭学院与展厅群

气质：讲座评图 · 学院系统 · 作品陈述

离线渲染农场

气质：算力缓存 · 工具重构 · 闭关预演

北方双年展工地

气质：大空间部署 · 团队协作 · 媒体关系

海外驻留港

气质：跨学科相遇 · 原型生产 · 赞助连接

每个大地图下面还有子地图，比如深港走廊里有"提案会议室""黑盒测试场"..."。进不同子地图，消耗不同资源，掉不同东西。

后勤与研发挂载

这就是你说的"类似种菜/挂渲染"机制：

  • 你可以在当前地图选一个项目"挂上"
  • 项目需要若干回合才能完成
  • 完成后给你对应的资源奖励，可能解锁新技能
  • 同一时间只能挂一个，你可以随时换，但进度不保留

已有项目类型：

  • 创作类：环幕失真仪式...
  • 申请类：驻留申请计划...
  • 整理类：技能模块化整理...
  • 商业类：品牌空间提案...
  • 理论类：方法论宣言重写...

为什么要"挂着"

因为真实创作就是这样：作品不是点一下就出来，它需要时间在后台"生长"。你挂上去，继续跑地图做行动，到点收成。这就是对"创作周期"的模拟。

资源与流转

所有行动都消耗资源，所有收获都增加资源。核心六种资源：

时间

最硬的通货。每行动一次就耗时间，时间到 20 回合就进入结局。

资金

维持创作的燃料。有些地图和项目要花钱，没钱寸步难行。

体力

高强度行动耗体力，体力太低会影响收益。需要找地方养。

名声

影响力货币。名声够了才能进高级区域，接大项目。

档案

你做过的东西积累下来就是档案。档案能解锁新可能性。

关系

在地图里认识 NPC 攒下的人情。关系能带来特殊事件。

NPC 与生态节点

NPC 不是剧情工具人，他们是制度环境的具象化：

  • 老炮张 → 出来早的地方实践者
  • 王教授 → 学院系统守门人
  • 甲方姐 → 品牌/赞助接口
  • 孟工 → 技术协作提供者
  • 开源幽灵 → 匿名知识社区
  • 驻留管理员 → 国际场域守门人

在不同地图遭遇不同 NPC，他们会给你不同的事件选项，影响你的资源和技能。

完整一局流程

测评倾向 → 推荐流派 → 选择壳体 → 装配初始技能 → 进入游戏
选地图/子地图 → 执行区域行动 → 可能遇 NPC → 可能掉技能 → 挂研发项目
回合 +1 → 项目推进 → 重复 → 20 回合 → 结局判定

一局大概 5-15 分钟，骨架已经闭环，可以完整玩完。

存档与后续扩展

  • 进度存在浏览器 localStorage，刷新不丢
  • 支持导出/导入存档 JSON，可以备份
  • 所有内容都在 data/ 层，加新流派/新地图/新技能只需要改 JSON 数据
  • 预留了后续接 AI 扩写对话和事件的口子，但第一阶段先把骨架做硬
