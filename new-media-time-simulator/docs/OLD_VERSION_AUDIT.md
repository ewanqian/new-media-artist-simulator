# 旧版审计：哪些内容值得继承

基于旧仓库 README，可确认旧版《新媒体艺术家模拟器》的强项主要不在前端工程，而在 **设定深度、场域观察和文本语气**。

## 可以直接继承的内容

### 1. 身份路径

旧版已有 6 条身份路径，这说明“角色入口”已经存在雏形。
新版将它升级为：

- 干员外壳 / archetype
- 测评推荐系统
- 流派与被动技能

### 2. 派系系统

旧版 9 大派系的价值很高，因为它们本质上是 **思想与美学流派**。
新版没有把它们原样硬塞进 UI，而是把它们拆进：

- 技能节点风格
- 地图倾向
- NPC 对话立场
- 未来可做的“学院 / 商业 / 开源 / 驻留”路线分歧

### 3. 核心 NPC

旧版明确了：

- 老炮张
- 王教授

这两个角色非常有用，因为他们分别代表：

- 圈内经验与毒舌现实
- 学术合法性与方法论判断

新版继续保留，并新增：

- 甲方姐
- 孟工
- 开源幽灵
- 驻留管理员

### 4. 空间设定

旧版列出了大量工作室 / 实验室 / 地域艺术生态，这正好适合升级成地图系统。

旧版的空间逻辑比“单纯叙事背景”更高级，因为它已经具备：

- 场域差异
- 价值判断差异
- 资源分布差异

新版把这些东西转换为：

- 全球地图
- 子地图
- 地图标签
- 行动类型
- 资源掉落倾向

### 5. 理论骨架

旧版最有价值的是：

- AI 时代主体性危机
- 布尔迪厄场域逻辑
- 学术资本 / 经济资本撕裂
- 新媒体艺术边界被重写

这些内容非常适合继续作为 **引擎理论层**，而不是只做成说明文案。

---

## 旧版不宜直接照搬的部分

### 1. 过长的纯文本结构

旧版文本非常完整，但如果直接塞进网页原型，会导致：

- 可玩性下降
- 开发迭代困难
- 前端结构臃肿

### 2. 过多静态设定

旧版很多内容像百科全书，适合存档，不适合直接当主游戏流程。
更适合转成：

- JSON 数据层
- NPC 事件池
- 地图资料库
- 图鉴系统

### 3. 以“概念解释”为主，而非“系统反馈”为主

旧版很强的一点是解释时代，但新版要把这些解释变成玩家可感受的反馈：

- 焦虑上涨
- 预算回流
- 项目挂载
- 技能掉落
- 关系变化

---

## 结论

旧版适合被视为：

- **世界观母本**
- **文本资料库**
- **NPC 与场域源文件**
- **理论引擎前身**

新版则应该作为：

- **可玩原型**
- **系统骨架**
- **后续图形化扩展底座**
