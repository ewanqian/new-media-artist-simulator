# V0.4 Text-first / Attention Loop

## 目标

把新媒体艺术家模拟器从“面板管理器”收缩成可以快速推进、长期积累的文字模拟器。

这一版不新增大世界，不做物品栏，不做技能树，不依赖 LLM。

## 核心循环

`收到信号 → 花注意力行动 → 项目/关系/资金发生变化 → 留下记录 → 下一周旧记录重新影响事件`

长期游戏的内容不是囤积物品，而是积累：

- 项目状态
- 未解决问题
- 技术债
- 关系线索
- 失败记录
- 被搁置的素材
- 可再次调用的档案节点

## 核心资源

### 注意力 Attention

- 每周 6 点。
- 每个主要行动消耗 0–3 点。
- 进入下一周恢复。
- 它代表时间、精神集中和创作窗口的综合限制。
- 它取代传统游戏的背包式资源堆叠，成为界面里最强的即时反馈。

### 资金 Cash

只作为现实约束，不做复杂经济系统。每周固定生活/工作室支出，商业工作、委托等可以补充现金。

## UI 层级

全屏只保留四层：

1. 顶部状态条：周数 / 注意力 / 资金。
2. 主文本流：邮件、群聊、现场、项目笔记、系统记录。
3. 行动区：始终最多 3 个选项，支持 1/2/3 键。
4. 右侧账本：当前项目、持续影响、档案；移动端折叠。

不再出现独立物品栏、任务栏、技能树、商店式入口。

## 图标系统

只使用单色线性小图标，并且只表达系统语义：

- eye：注意力
- money：资金
- clock：时间
- project：项目
- message：文本/通信
- node：持续关系/节点
- archive：档案
- signal：外部反馈

图标不承担装饰，不使用大尺寸插图化 icon。

## 文本系统

事件不是一段旁白 + 三个善恶选项，而是来自不同“职业界面”的文本：

- OPEN CALL 邮件
- 拒信
- 群聊邀约
- 技术故障日志
- 布展现场记录
- 项目笔记
- 预算/报价
- GitHub issue / 网页维护
- 档案回调

每条事件都应满足：

`具体情境 → 具体动作 → 可见即时结果 → 产生一个未来条件`

禁止大量使用“探索边界、跨界融合、提升影响力、拓展人脉”等没有可操作对象的句子。

## 长期性

长期性来自状态组合，而不是无限添加新菜单：

- 被拒绝的申请材料之后可以变成项目页面。
- 崩溃日志可以变成作品时间结构。
- 被搁置的录音可以在数周后因为新事件重新命中。
- 技术债会在真正需要长期运行时回来。
- 关系不显示成 RPG 好感度，但会改变谁会再次联系你。
- 项目暂停不是失败；它可能在之后以另一个媒介重新出现。

## V0.4 测试标准

这版只验证：

1. 不看教程，是否能在 30 秒内完成前三次行动。
2. 连续推进 5–10 周时，是否产生“这是我之前造成的”反馈。
3. UI 是否足够安静，让玩家主要阅读文本而不是管理面板。
4. 是否愿意为了看旧项目如何回来而继续点击。
5. 文字是否足够具体，能够区分媒体艺术职业场景与普通人生模拟器。
