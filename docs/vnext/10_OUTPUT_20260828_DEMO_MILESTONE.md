# OUTPUT Digital Gallery · 2026-08-28 Demo Milestone

## 外部目标

2026-08-28，上海北外滩 OUTPUT Digital Gallery 三楼 Open Day。独立游戏 Demo 体验区预计 12–15 个项目；现场面向真实玩家、创作者和行业从业者。

报名截止：2026-08-24 24:00。

项目：**新媒体艺术家模拟器 / New Media Artist Simulator**。

这次不是“展示我们做了多少系统”，而是验证：

> 一个第一次见到本项目的人，能否在 10–20 分钟内理解它是什么、做出至少 3 次有意义的决定、亲手修改一次作品系统，并带走一个足够具体的记忆点。

---

## 20 分钟试玩目标

### 0:00–2:00 / 进入
- 进入首页后最多一次点击进入生涯。
- 不出现第二层“新游戏 / 继续”重复菜单。
- 预置一个适合现场的 Demo Career Profile；允许玩家跳过角色问卷。
- 第一屏只回答三个问题：我是谁？现在发生什么？我能做什么？

### 2:00–5:00 / 第一次决定
- 通过短文本和 2–3 个选择形成第一个 Project Seed。
- 选择必须改变后续节点、人物、证据或项目条件。
- 注意力、现金、时间只参与后果，不因“点数不够”让试玩卡死。

### 5:00–10:00 / 第一次工作图
- 打开 Blueprint Graph。
- 玩家至少完成：拖动一个节点、添加一个节点、连接一次输入/输出、改变一个参数。
- 当前 Brief、场地条件、设备和资源直接注入图中，不经过冗长“进入环境”流程。
- 目标明确：让系统运行 / 让它适应一个现实条件 / 修一个明确问题。

### 10:00–14:00 / RUN → FAIL → MODIFY
- 一键 RUN。
- 系统产生可读结果：正常链路、延迟、输出能力、现场约束、故障或资源缺口。
- 玩家从 2–3 个真实方案中决定：替换节点、降级 Scope、借资源、增加备用、改观看方式等。
- 再 RUN，一次改动产生可见差异。

### 14:00–17:00 / 人与现场
- 引入一个强 NPC / 同行 / 技术人员 / 场地方。
- NPC 不给分数，而以不同 Lens 阅读玩家当前版本。
- 产生一条可追溯的 Evidence / Note / Thread。

### 17:00–20:00 / 归档与记忆点
- 当前版本进入 RECORDS。
- 展示：Blueprint、失败版本、方法、场地 Note、人物关系、Remix lineage。
- 给玩家一个明确的“这是我刚才做出来的东西”的结果。
- 可选：生成 Blueprint Code / 导出 `.nmas.json`。

## Demo 必须保留的核心结构

### 玩家可见玩法只有两类
1. **READ / 阅读**：剧情、人物消息、现场说明、运行结果、档案。
2. **DECIDE / 决策**：选方案、搭图、改图、决定是否承诺/降级/借资源/发布。

任何第三类纯菜单劳动都需要被质疑。

### FIELD / WORKBENCH / RECORDS 仍然存在，但不是三个反复浏览的菜单
- FIELD：把现实条件、人物、机会、限制注入当前 Project / Blueprint。
- WORKBENCH：主要游戏画面；Build / Run / Modify。
- RECORDS：保存已经发生的历史、Evidence、Methods、Blueprint、Triumphs。

### 环境不是页面，是条件
场地切换应接近：

`BLACKBOX · 2H · Projector + LED · 禁止吊装 · 1 技术人员 [切换]`

点击后即时切换条件；不再先打开“地点详情 → 阅读 → 进入环境”。

## 试玩版本的 6 个记忆点

1. **第一根线接上以后，它真的开始运行。**
2. **同一个作品换一个场地，突然不成立。**
3. **一个故障不是惩罚，而变成可保存的方法。**
4. **缺的不是设备，而是认识能借到设备的人。**
5. **删掉几个节点以后，作品反而更清楚。**
6. **最后打开档案，看到刚才 20 分钟已经形成一条自己的谱系。**

Demo 至少稳定触发其中 3 个。

## 内容填充优先级

### P0 / 8 月 28 日前必须
- 首页进入路径去重。
- Demo Profile 一键开局。

- 3 个 NPC Lens：同行 / 技术 / 机构。
- 3 个特殊事件：Scope +1 / 信号漂移 / 关键设备缺席。
- 6–10 篇 Archive / Ecology / Method 可读内容。

### P2 / 现场加分
- Blueprint QR / 分享码。
- Demo Reset 一键清档。
- 试玩结束摘要。
- 观众反馈记录模式。
- 现场“开发者演示档”和“玩家自由档”快速切换。

## 现场测试标准

试玩前进行至少 10 次完整冷启动测试：
- 5 次桌面鼠标键盘；
- 3 次触摸板；
- 2 次从空 LocalStorage 开始；
- 每次必须 20 分钟内完成核心闭环；
- 不允许存在无法返回、重复标题页、遮挡菜单、白底白字、关键按钮因资源不足永久禁用。

记录每次：
- 玩家在第几分钟第一次理解“这是在做什么”；
- 第一次主动尝试节点编辑发生在第几分钟；
- 哪段文本没读；
- 哪个按钮找不到；
- 哪个结果让玩家主动说话或笑；
- 最后能否复述游戏核心。
